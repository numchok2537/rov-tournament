# ตั้งค่าระบบจัดการแข่งขัน (ใช้ครั้งเดียว ~5 นาที)

ไม่ต้องสร้าง Google Sheet เลยครับ ใช้ Apps Script เปล่าๆ เก็บข้อมูลในตัวมันเอง

1. เปิด [script.google.com](https://script.google.com) → กด **โปรเจกต์ใหม่ (New project)**
2. ลบโค้ดเดิมในไฟล์ `Code.gs` ทิ้ง แล้ววางโค้ดจากไฟล์ `apps-script/Code.gs` ในโปรเจกต์นี้ลงไปแทน
3. กด **บันทึก** (ไอคอนแผ่นดิสก์) — ตั้งชื่อโปรเจกต์อะไรก็ได้ เช่น "ROV Tournament"
4. กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้ใหม่ (New deployment)**
   - กดไอคอนเฟือง ข้าง "Select type" → เลือก **เว็บแอป (Web app)**
   - Execute as: **Me (บัญชีของฉัน)**
   - Who has access: **Anyone (ทุกคน)**
   - กด **Deploy**
5. ครั้งแรกจะมีหน้าต่างขอสิทธิ์ — เลือกบัญชี Google ของอาจารย์ → กด "Advanced" → "Go to (ชื่อโปรเจกต์) (unsafe)" → Allow (ปลอดภัย เพราะเป็นสคริปต์ที่อาจารย์เพิ่งวางเอง)
6. คัดลอกลิงก์ **Web app URL** ที่ได้ (ขึ้นต้นด้วย `https://script.google.com/macros/s/.../exec`)
7. ส่งลิงก์นั้นมาให้ผม ผมจะเชื่อม `js/config.js` ให้เสร็จเลยครับ

## รหัสผ่านหน้าแอดมิน

ค่าเริ่มต้นคือ `1234` — แนะนำให้เปลี่ยน:

1. ใน Apps Script เปิดเมนู **Project Settings** (รูปเฟือง) → เลื่อนลงมาที่ **Script Properties**
2. กด **Add script property** → Property = `ADMIN_PASSCODE`, Value = รหัสที่ต้องการ → Save

## ถ้าอยากเริ่มทัวร์นาเมนต์ใหม่

กดปุ่ม "เริ่มใหม่ (ล้างทีมทั้งหมด)" ในหน้าแอดมินได้เลย ไม่ต้องกลับมาที่นี่
